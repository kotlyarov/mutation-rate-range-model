# First Model Report

Status: not written yet.

This report should be created after the current lineage mutation-selection
model has been validated against basic mathematical checks and reviewed against
the intended scientific assumptions.

## Required Contents

The first report should include:

- model version
- parameter set
- reviewed model choices and remaining limitations
- lineage trajectory plots
- population and weighted mean fitness by generation
- beneficial, harmful, lethal, and neutral mutation summaries
- sensitivity analysis
- known unrealistic behaviours
- interpretation limits

Mutation-rate range estimates such as `mu_min`, `mu_peak`, and `mu_max` should
wait for a reviewed mutation-rate sweep rather than a single-run report.

## Required Caution

The report must state that the model is exploratory and assumption-dependent.

Do not claim that the model has found a true biological optimum.
