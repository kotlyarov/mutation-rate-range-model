# First Model Report

Status: not written yet.

This report should be created after the first deterministic implementation exists.

## Required contents

The first report should include:

- model version
- parameter set
- curve plots
- estimated `mu_min`, `mu_peak`, and `mu_max`
- sensitivity analysis
- known unrealistic behaviours
- interpretation limits

## Required caution

The report must state that the first model is exploratory and assumption-dependent.

Do not claim that the model has found a true biological optimum.
